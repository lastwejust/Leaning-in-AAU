# 提醒与警告

!!! warning "上传前请务必看完这一页"
    以下内容不适合上传。如果你认为缺少它们会影响资料完整性，请优先放在校内课程平台，或联系任课教师，由教师决定是否公开。

## 版权 { #copyright }

- **不要上传盗版教材、付费电子书、整本扫描件。** 需要教材时，写书名、作者、版本、ISBN，或给出图书馆、正规购买链接。
- **不要上传盗版、破解版、绿色版付费软件及其安装包、序列号、注册机。**
- **不要上传教师明确要求不公开的课件、试卷、答案。** 课程平台、教师主页上标注“禁止传播”的内容，先获得许可再传。
- 转载别人的笔记、图片、代码，注明来源和作者；不要去除水印或版权声明。
- 资料来自网络时，先确认可以分享；不确定就不要传。

## 隐私 { #privacy }

- 删除或打码：姓名、学号、班级、成绩、身份证号、手机号、宿舍号。
- 不要上传他人未授权的照片、聊天记录、成绩单。
- 不要上传含个人联系方式的作业、简历、报名表。

## 学术诚信 { #integrity }

- 作业、实验报告、课程设计可以作为参考，但**不要直接抄袭**。
- 不提供代写、代考、作弊资料，也不鼓励用往年试卷押题。
- 答案和解析仅供参考，不保证正确；以教师讲解和教材为准。

## 考试相关 { #exam }

- **只上传考试结束后的试卷。** 正在进行的考试、补考、缓考题目和答案，一律不要传。
- 回忆版试卷标注“回忆版”，并说明题面可能不完整。
- 老师要求回收、保密或禁止带出考场的试卷，不要上传。
- 不要为了“求答案”在考试期间发 Issue。

## 如果侵犯了你的权益 { #takedown }

如果你是本仓库某份资料的权利人，且不希望它被公开：

1. 到 [Issues](https://github.com/lastwejust/Learning-in-AAU/issues) 发一条标题为 `[侵权删除] 文件路径` 的 Issue；
2. 写清楚具体文件路径和理由。

核实后会尽快删除。请勿在 Issue 里公开身份证号、电话等个人隐私。

也可以直接发邮件到 [zhang.x.w@ahau.edu.cn](mailto:zhang.x.w@ahau.edu.cn)。

## 上传前自检

- [ ] 这份资料我有权分享吗？
- [ ] 老师有没有要求不要外传？
- [ ] 文件里有没有姓名、学号、成绩等隐私？
- [ ] 文件名是否符合“学年学期_课程名_资料类型”？
- [ ] 试卷是否注明期末 / 期中、A / B 卷、回忆版、是否含答案？
- [ ] 文件是否放进了正确的学院和课程文件夹？
- [ ] 单个文件是否超过 25 MB？
