# 常见问题

## 找资料

??? question "为什么没有我们专业的课？"
    因为还没人上传。你可以在对应学院下新建课程文件夹，或者发 [Issue](https://github.com/lastwejust/Learning-in-AAU/issues) 求资料。

??? question "搜索搜不到怎么办？"
    课程名可能有别名（比如“高数”和“高等数学”）。试试只搜两三个字，或者按分类进去一层层点。

??? question "同一门课有好几个版本，看哪个？"
    先看课程文件夹里的 `README.md`，通常会写明适用专业和年份。年份越新越接近现在的考法。

## 下载

??? question "下载后打不开怎么办？"
    PDF 用浏览器或 PDF 阅读器；`.docx` / `.pptx` 用 Office 或 WPS；`.zip` 用系统解压或 7-Zip。手机打不开就换电脑。

??? question "整个仓库太大了，怎么只下一门课？"
    直接点单个文件下载。GitHub 没有官方“单文件夹下载”按钮，第三方工具可以用，但要注意安全。

??? question "文件损坏 / 只有几 KB？"
    多半是下载中断。重新下载一次；还是不行就在 Issue 里说一声，注明文件路径。

## 上传

??? question "我不是计算机专业，能上传吗？"
    能。用网页版 **Add file** → **Upload files** 就行，不需要学 Git 命令。

??? question "上传错了、想删除怎么办？"
    网页上打开文件 → 右上角 **Delete file**；文件夹在 GitHub Desktop 里删除后提交。不会操作就发 Issue，注明路径。

??? question "为什么我传的文件没显示？"
    检查三点：是不是传到了仓库根目录（应该进对应课程文件夹）；文件名是否含非法字符；提交有没有点确认。

??? question "可以传 Word / PPT 吗？"
    可以。课件优先传原始 PPT 或 PDF，同一内容不要重复传两份。

## 规则

??? question "试卷没有答案，正常吗？"
    正常。很多试卷是同学回忆或整理的，答案不一定有，也不保证正确。以老师讲解为准。

??? question "可以拿这些资料去卖吗？"
    不可以。本仓库内容仅供学习交流，禁止商业使用、倒卖、付费引流。

??? question "可以整库转载吗？"
    转载自己整理的部分可以，请保留出处、署名，遵守 CC BY-NC-SA 4.0。第三方资料版权归原作者，转载前自行确认授权。

??? question "老师要求删除某份资料怎么办？"
    发 `[侵权删除]` Issue，或直接发邮件，我们会尽快处理。

??? question "为什么用中文文件夹名？"
    方便同学一眼看懂。只要不用空格和 `\ / : * ? " < > |`，GitHub 对中文路径支持是正常的。

## 网站

??? question "网站打不开 / 加载很慢？"
    本站托管在 GitHub Pages，国内访问偶尔不稳定。换网络再试，或直接访问 [GitHub 仓库](https://github.com/lastwejust/Learning-in-AAU)。

??? question "为什么 README 这么短？"
    首页只放导航和最短说明，详细内容拆到独立页面，点链接就能看。

??? question "网站上的课程索引不全？"
    索引根据仓库实际文件生成，有资料才会出现。没列出来的课程，就是还没人上传。
