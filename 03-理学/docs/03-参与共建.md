# 参与共建

不需要会 Git，也不需要先加权限。

## 投稿方式 { #submit }

### 方式一：Pull Request（推荐）

1. 打开 [仓库](https://github.com/lastwejust/Learning-in-AAU)，点右上角 **Fork**。
2. 在你自己的 Fork 里进入对应文件夹，点 **Add file** → **Upload files**。
3. 上传完点 **Contribute** → **Open pull request**。
4. 等维护者审核合并。

### 方式二：Issue

在 [Issues](https://github.com/lastwejust/Learning-in-AAU/issues) 发一条“资料投稿”，把文件拖进正文，维护者代传。

### 方式三：邮件

发到 [zhang.x.w@ahau.edu.cn](mailto:zhang.x.w@ahau.edu.cn)，写清楚：

- 课程名
- 资料类型（课件 / 笔记 / 试卷 / 实验报告）
- 学年学期
- 是否含答案

!!! warning "隐私资料走邮箱"
    含姓名、学号、成绩等隐私的文件，不要发 Issue，直接发邮箱。

!!! tip "投稿时留个名字"
    通过 Issue 或邮件投稿，写一下你的 GitHub 用户名 / 昵称（没有就写希望怎么署名），方便记到贡献者名单。

!!! info "普通投稿不需要权限"
    只有长期负责某个学院 / 课程的共创者，才会给 Write 权限。传一两份资料，用 PR、Issue 或邮件就够了。

| 角色 | 能做什么 | 需要会什么 |

| 浏览者 | 查看、下载资料 | 会打开网页就行 |
| 投稿者 | 把资料发给维护者，由维护者代传 | 不需要 GitHub，发 Issue 或邮件即可 |
| 共创者 | 直接上传、整理自己负责的学院 / 课程 | 会用网页版 GitHub 即可 |
| 维护者 | 管理权限、审核、处理侵权和结构问题 | 目前由 @lastwejust 负责 |

### 怎么加入 { #join }

1. 发邮件到 [zhang.x.w@ahau.edu.cn](mailto:zhang.x.w@ahau.edu.cn)，或到 [Issues](https://github.com/lastwejust/Learning-in-AAU/issues) 说“我想参与维护”。写清楚：
    - GitHub 用户名
    - 学院 / 专业 / 年级
    - 想负责的学院或课程
    - 大概能投入的时间
2. 我会和你确认分工和规则（不考试、不用写申请信）。
3. 确认后加为 **collaborator（Write 权限）**；接受 GitHub 邀请后就能直接上传。
4. 第一次上传前看一遍下面的规则；建议先传 1 门课试试，不强制。

!!! danger "权限只给 Write"
    Write 能上传和修改文件；Admin 能改仓库设置、甚至删仓库。Admin 只留给自己。

### 共创者规则 { #rules }

- **先 Pull 再上传**：GitHub Desktop 先 `Fetch origin` → `Pull origin`；网页上传前先刷新。
- **只动自己负责的课程**：删除、重命名、移动整个文件夹，先在 Issue 说一声。
- **不重复上传**：同一份资料只放一个地方。
- **控制体积**：网页单文件 ≤25 MB，GitHub 单文件上限 100 MB；扫描件压缩 / 拆章。全库先控制在 1 GB 以内。
- **不传**：盗版教材、付费电子书、破解软件、老师要求保密的内容、含个人隐私的文件、考试进行中的题目。
- **Commit 说明**：`添加 课程名 学年学期 资料类型` / `修正 课程名 文件名` / `删除 课程名 过期资料`。
- **毕业交接**：卸任前把负责的课程和未完成事项交接给下一届。

## 文件大小与外部链接 { #size }

网站会把资料复制一份到站点里，方便同学直接下载。但有两个硬限制：

| 限制 | 数值 | 谁定的 |
| :--- | :--- | :--- |
| 单个文件进站上限 | **24 MB** | 本站设置（Cloudflare 单文件上限 25 MB） |
| GitHub 仓库单文件上限 | 100 MB | GitHub |
| 单个部署文件数 | 20,000 个 | Cloudflare Pages |

### 超过 24 MB 怎么办

按优先级选一种：

1. **压缩**
   - PPT → 另存为 PDF，通常能小一半；
   - PDF → 用压缩工具降到 150–200 dpi；
   - 图片 → 转 JPG，质量 80。
2. **拆分**
   - 按章节拆成 `第1章.pdf`、`第2章.pdf`；
   - 一门课拆成「课件」「试卷」两个文件夹分别传。
3. **放网盘，站内贴链接**
   - 阿里云盘、夸克、百度网盘都行；
   - 在课程文件夹的 `README.md` 里写清楚：`完整版见网盘：<链接>`；
   - 站点索引里会保留这门课，同学点进 README 就能看到外链。

!!! tip "视频不要进仓库"
    录屏、网课视频请放 B 站或网盘，仓库只放链接。视频动辄几百 MB，会把仓库和构建拖垮。

### 大文件在网页上的表现

| 文件大小 | 在线预览 | 直接下载 |
| :--- | :--- | :--- |
| ≤ 10 MB | PDF 一般能预览 | 可以 |
| 10–24 MB | PDF 可能加载慢 | 可以，但手机容易失败 |
| > 24 MB | 不托管 | 只能走 GitHub 或网盘 |
