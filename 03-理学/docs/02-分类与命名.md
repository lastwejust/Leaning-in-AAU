| `02` | 工学 | 工学门类各学院的课程 |
| `03` | 理学 | 生命科学、生物制造等理学方向课程 |
| `04` | 经济管理学院 | 经管类课程 |
| `05` | 人文社会科学学院 | 人文社科类课程 |
| `06` | 马克思主义学院 | 马院专业课程（思政公共课放 `00`） |
| `07` | 外国语学院与国际教育学院 | 外语类专业课程（大学英语放 `00`） |

## 命名规范 { #naming }

文件夹和文件名用中文、数字、下划线，**不要用空格**，也不要用 `\ / : * ? " < > |`。

### 课程文件夹

用教务系统里的正式课程名，不加年份、老师名和“资料”二字。

```text
高等数学（分级）
大学物理
植物病理学
机械设计基础
```

### 资料文件

推荐格式：

```text
学年学期_课程名_资料类型_补充说明.扩展名
```

示例：

```text
2024-2025-1_高等数学A1_期末试卷_回忆版.pdf
2024-2025-1_高等数学A1_期末试卷_参考答案.pdf
2023-2024-2_大学物理B_期末试卷_A卷_含答案.pdf
第03章_导数与微分_课堂笔记.pdf
实验02_牛顿环_实验报告模板.docx
```

!!! tip "命名要点"
    - `2024-2025-1` 表示 2024 年秋季学期，`-2` 表示春季学期。
    - 试卷注明：期末 / 期中 / 补考 / 缓考，A 卷 / B 卷，回忆版，含答案 / 无答案。
    - 不要用 `新建文件夹`、`最终版`、`真的最终版`、`QQ图片20240101`。
    - 扫描件尽量转 PDF，200～300 dpi；太大就拆分。
    - 网页单文件建议 ≤25 MB；GitHub 单文件上限 100 MB。

## 几个容易放错的点

1. **思政课、大学英语放 `00`**，不要放 `06` / `07`。
2. **同一门课由多个学院开设**：放“主要开课学院”，其他学院不重复放。
3. **材料与化学学院、资源与环境学院**分“理科方向”和“工科方向”，按课程代码或培养方案放。
4. **新增学院**：直接建文件夹，顺手更新这一页的目录树。
5. **实在不确定**：发 [Issue](https://github.com/lastwejust/Learning-in-AAU/issues) 问，不要硬塞进 `00`。

## 隐私检查 { #privacy }

上传前检查一遍：

- [ ] 姓名、学号、班级、成绩、身份证号、手机号、宿舍号
- [ ] 作业 / 实验报告封面、页眉页脚、PDF 属性里的作者名
- [ ] 聊天记录截图里的头像、昵称、群名

有的话先打码或删除。
