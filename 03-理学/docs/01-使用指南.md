# 使用指南

不需要注册也能浏览和下载。这一页讲三件事：**怎么找、怎么看、怎么下载**。

## 1. 找到你的课 { #find }

### 方法一：按分类找

从首页或顶部导航进入 [`00`～`07`](02-分类与命名.md#tree)，再点学院、点课程。

### 方法二：搜文件名

在 GitHub 仓库首页按键盘上的 ++t++，输入课程名或文件名，例如 `高等数学`、`期末试卷`。

### 方法三：用 GitHub 搜索

在 GitHub 顶部搜索框输入：

```text
repo:lastwejust/Learning-in-AAU 高等数学
```

把 `高等数学` 换成你要找的课程名。

### 方法四：看课程索引

本站的 [课程索引](06-课程索引.md) 列出了当前有资料的课程，点一下直接跳到 GitHub 对应文件夹。

## 2. 在线看 { #view }

- **Markdown、PDF、图片**：通常可以直接在网页里预览。
- **`.docx` / `.pptx` / `.zip`**：需要下载后用 Office、WPS 或解压软件打开。
- PDF 加载很慢，或提示文件过大：先下载再看。

!!! tip "手机上看 PDF"
    手机浏览器打开大 PDF 容易失败。可以长按「下载」按钮，选“在新标签页打开”，或直接下载到本地再看。

## 3. 下载 { #download }

### 只下载一个文件

打开文件页面，点右上角的下载按钮（**Download raw file** / 中文界面「下载原始文件」）。

如果找不到按钮：点 **Raw**（原始文件），再按 ++ctrl+s++ 保存。

### 下载整个仓库

在 GitHub 仓库首页点绿色 **Code** → **Download ZIP**，解压即可。

!!! warning "ZIP 会很大"
    仓库资料越多，ZIP 越大。只想看一两门课，别下整包，直接点单个文件。

### 只下载一个文件夹

GitHub 没有官方的“单文件夹下载”按钮。可以：

1. 下载整个仓库的 ZIP，解压后只取需要的文件夹（最稳）；
2. 用 GitHub Desktop 克隆后复制；
3. 用 GitZip、DownGit 等第三方工具（方便，但注意隐私和文件安全）。

### 在手机上

可以浏览、预览、下载单个文件。**整包 ZIP 和大文件建议用电脑**。

## 4. 看更新 { #update }

- 点仓库右上角 **Watch** → **All Activity**，有更新时 GitHub 会通知你。
- 点 **Commits** 看每次改了什么。
- 点 **Star** 收藏，以后在个人主页的 **Your stars** 里能找到。

## 5. 找不到资料怎么办 { #help }

到 [Issues](https://github.com/lastwejust/Learning-in-AAU/issues) 点 **New issue**，标题写：

```text
[求助] 课程名 - 需要的资料类型
```

正文写上：学院、专业、年级、课程名、需要的资料（例如“2023-2024-1 期末试卷”）。

!!! danger "考试期间别求题"
    正在进行的考试、补考、缓考题目和答案，一律不要发 Issue 索要。

## 打不开网站怎么办

本站是 GitHub Pages 静态站，国内访问偶尔会慢或打不开。

- 换一个网络（流量 / 校园网互换）再试；
- 直接访问 **GitHub 仓库**：<https://github.com/lastwejust/Learning-in-AAU>
- 还是不行，发邮件到 [zhang.x.w@ahau.edu.cn](mailto:zhang.x.w@ahau.edu.cn)，说明你要的课程。
