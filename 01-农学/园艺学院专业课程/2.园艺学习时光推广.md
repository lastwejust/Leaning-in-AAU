## 前言

从第一次踏进安农的教室，到一门一门把课上完，每个人手里都会攒下一堆资料和情报：

- 有的是要满网搜索的电子书，运气好一搜就有，运气差翻遍全网也找不到；
- 有的是学长学姐精心整理的真题和复习提纲，只能在 QQ 群文件里代代相传，毕业即失散；
- 有的是上完课才恍然大悟的技巧——原来这门课重点是这个，当初本可以轻松不少。

这些信息大多是隐晦的、零散的、口口相传的。一届又一届，同样的弯路被不同的人重复走。

我们希望把它们变成**公开的、易于获取的、大家能共同完善**的资料。本站以园艺学院培养方案为蓝本，逐学期整理课程资料。让每一届的经验都能留下来，而不是散落在毕业时的聊天记录里——这是「安农学习时光」存在的原因。

## 课程资料

> 课程目录以**园艺学院本科人才培养方案**为蓝本整理，覆盖大一至大四全部学期；其他学院同学同样可以按图索骥，公共课与通识课部分通用。

| 学期 | 入口 | 主要课程 |
| :--- | :--- | :--- |
| 大一上 | [大一第一学期](./docs/02-课程资料/01-大一第一学期/) | 高等数学Ⅲ、无机化学Ⅱ、大学英语 1 |
| 大一下 | [大一第二学期](./docs/02-课程资料/02-大一第二学期/) | 有机化学Ⅱ、植物学、生物统计 |

## 参与贡献

欢迎提交 Pull Request —— 补一份真题、修一个死链、加一条避坑心得，都算数。

### 方式一：网页上传（不会 git 也能贡献）

1. Fork 本仓库
2. 上传文件到**已有文件夹**：进入对应课程目录，点 `Add file` → `Upload files`，把文件拖进去
3. 上传文件到**新文件夹**：在上传框里把文件名写成 `新目录名/文件名`（如 `试卷与答案/2024期末.pdf`），GitHub 会自动创建目录
4. Commit 到自己的仓库后，点 `Contribute` → `Open pull request` 发起 PR

也可以把资料直接附在 Issue 里，由维护者代为添加。

### 方式二：git 流程

1. Fork 本仓库并新建分支：`git checkout -b add-高数Ⅲ真题`
2. 把文件放进对应课程的 `课件/`、`试卷与答案/`、`复习资料/` 子目录（单个文件请勿超过 50 MB，超大资源不进仓库，网盘链接登记到对应课程页的「大文件」小节）
3. 发起 Pull Request，说明补了哪门课的什么资料

放进资料目录的文件会**自动出现在课程页的清单里**，无需手动编辑页面。

---

### ⚠️ 不适合上传的内容

- 盗版电子书 / 付费电子书
- 盗版、破解版付费软件及其安装包
- 课程/教师主页上列出的内容（未经教师许可请勿搬运）
- 正在进行的考试的试题与答案

如果缺少这些资料会影响完整性，建议写个说明文档放链接或指引文字，帮助大家找到资源。
