## 这里有什么

课件、笔记、实验报告、往年试卷、复习提纲、选课经验，以及教材的书目信息。

**不收录**：盗版教材、付费电子书、破解软件、老师要求保密的内容、含个人隐私的文件、考试进行中的题目。

## 一起维护

- **只想投资料**：不用加权限，Fork + PR、Issue 附件、发邮件都可以。
- **想长期维护**：欢迎自荐；我确认后加 Write 权限，负责一个学院或 1–2 门课。
- **不会 GitHub**：把文件发到 [zhang.x.w@ahau.edu.cn](mailto:zhang.x.w@ahau.edu.cn)，我来代传。

详细规则见 [参与共建](docs/03-参与共建.md)。

## 提醒

- 只传老师允许公开的内容。
- 不传盗版、隐私、保密内容和考试中的题目。
- 资料仅供参考，请以教务处、学院和任课教师的最新要求为准。

完整说明见 [提醒与警告](docs/04-提醒与警告.md)。
